# Time for Funny, Ready to Study! Основная идея проекта
Что это такое? Time for Funny, Ready to Study (Сокращенно - TfFRtS) - главный друг всех обучающихся. он поможет правильно распоряжаться временем и соблюдать комфортный рабочий график, не тратя время на соцсети или игры. Пока что приложение находится в разработке, поэтому некоторая часть функций не работает.

# Под капотом
Библиотеки для Python, уже использующиеся в Desktop-версии: flet, winreg, psutil, hmac, AppOpener, win32gui, re, os, time, psutil, datetime, win32process.

# Минимальная версия приложения
Минимум 6 рабочих сценариев ограничений, режим "Анализа", понятный интерфейс, Модуль мотивации, защита от несанкционирования отключения контроля

# Инструкция к установке
Распакуйте архив TfFRtS.rar в проект, например, в pycharm, для запуска "визуальной" части запустите "Start.py", для бэкэнда - main.py и/или watcdog.py
!!ВАЖНО:!! Работает только на windows! (windows 10)
